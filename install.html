SlimeBeep

A bubble gum beep messenger for Bondage Club. Made by SlimeQueenSamantha.

🔖 Bookmark (no extension needed)

  1. Show your bookmarks bar (Ctrl + Shift + B).
  2. Drag this button onto it:
    🫧 SlimeBeep
  3. Open Bondage Club, log in, then click the SlimeBeep bookmark. The pink slime appears.

Click it each time you open the game. It always loads the newest SlimeBeep, so there's never anything to update. Clicking it twice does nothing extra.

🐒 Userscript (loads by itself)

With Violentmonkey or Tampermonkey: install SlimeBeep. It starts with the game every time, and updates itself.
